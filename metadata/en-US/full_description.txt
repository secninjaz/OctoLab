OctoLab is a free and open-source Android client for GitLab. It works with gitlab.com as well as self-hosted GitLab instances (Community or Enterprise Edition).

FEATURES

Authentication
* Personal Access Token (PAT) login
* Multi-account support — add and switch between several GitLab accounts, self-hosted and gitlab.com side by side

Issues
* Browse, create, edit and comment on issues
* Filter by label, assignee or milestone

Merge Requests
* View merge requests, comment, review diffs
* Follow CI/CD pipeline status

To-dos
* View and filter your to-do list by action type (assigned, mentioned, review requested, etc.)

Activity
* Your activity feed, plus your projects' and starred projects' activity

Repository
* Browse files, README, branches, tags, commits and releases

Notifications
* Push notifications for new to-do items

Other
* Dark and light theme
* Markdown rendering — GFM tables, task lists, code blocks, images

No tracking, no analytics, no proprietary services.

OctoLab began as a GitLab-focused fork of Octodroid (gh4a), an open-source GitHub client, and is maintained by SecNinjaz.

Source code: https://github.com/secninjaz/OctoLab
